What this converter does

• Decodes LeviMap MMR1 tile records, including Zlib-compressed and sparse-pixel records.
• Reconstructs 16×16 pixel tiles into 256×256 pixel regions, then stitches regions using their region_x_y coordinates.
• Exports the complete mapped footprint, preserving transparent unexplored areas.
• Reads waypoints from LeviMap's waypoints/dim_N/waypoints.json and can package them as TXT.
• Ignores cave layers and waypoint overlays; this export uses the surface map.
Large images need substantial phone memory. The app does not impose a 10,000-pixel cap, but Android Chrome and the device GPU/browser still have their own canvas and memory limits.
