About conversion

MMR image decoder is not yet built into this version.
It can identify LeviMap MMR1 archives and inspect their region layout, but it cannot yet reconstruct new PNG maps from raw .mmr files. I’m keeping this limitation visible rather than giving you a broken or misleading export button.

The next development step is porting LeviMap’s native MMR1 decoding and tile-rendering logic into a browser-compatible engine. The Android .so is an ARM64 native library tied to its game/mod environment, so a normal web page cannot simply load it.
